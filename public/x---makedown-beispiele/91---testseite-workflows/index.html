    AstroLyrax

    Das passt sehr gut zu deinem Anwendungsfall. Gerade bei Astrofotografie-Workflows kann Mermaid deutlich mehr als nur einfache Kästen mit Pfeilen. Mit ein paar Stilmitteln bekommt man Diagramme, die fast wie technische Dokumentationen aussehen.

    Ich zeige dir einige Muster, die du direkt in Obsidian verwenden und anpassen kannst.

    1. Professioneller Standard-Workflow mit Gruppen

    Ein typischer Bildbearbeitungsablauf:

    ```mermaid
flowchart LR

    %% Bereiche definieren
    subgraph RAW["📷 Rohdaten"]
        A[Lights]
        B[Dark Frames]
        C[Flat Frames]
    end

    subgraph PRE["⚙️ Vorverarbeitung"]
        D[Kalibrieren]
        E[Registrieren]
        F[Stacking]
    end

    subgraph PROC["🎨 Bildbearbeitung"]
        G[Gradient entfernen]
        H[Entrauschen]
        I[Farbkalibrierung]
    end

    subgraph FINAL["✨ Finale Schritte"]
        J[Sterne bearbeiten]
        K[Schärfen]
        L[Export]
    end

    A --> D
    B --> D
    C --> D

    D --> E
    E --> F

    F --> G
    G --> H
    H --> I

    I --> J
    J --> K
    K --> L


    style RAW fill:#263238,color:white
    style PRE fill:#37474f,color:white
    style PROC fill:#455a64,color:white
    style FINAL fill:#546e7a,color:white
```

    Vorteil: Man erkennt sofort die Prozessphasen.

    2. Workflow mit Entscheidungen

    Sehr praktisch, wenn du abhängig vom Ergebnis unterschiedliche Wege gehst:

    Beispiel: Sternbearbeitung

    ```mermaid
flowchart TD

    A[Linearisiertes Bild]

    A --> B{Sterne getrennt?}

    B -->|Ja| C[Sternenebene bearbeiten]
    B -->|Nein| D[Sterne extrahieren]

    D --> C

    C --> E{Sterne zu dominant?}

    E -->|Ja| F[Sterne reduzieren]
    E -->|Nein| G[Original belassen]

    F --> H[Weiter zu Finalisierung]
    G --> H

    style B fill:#ffcc80
    style E fill:#ffcc80
    style H fill:#81c784
```

    Die gelben Rauten zeigen sofort: Hier muss eine Entscheidung getroffen werden.

    3. Workflow als Pipeline (ideal für deine Bildbearbeitung)

    Sehr übersichtlich für PixInsight-, Photoshop- oder Siril-Abläufe:

    ```mermaid
flowchart LR
	
	A["🌌 Aufnahme"] 
	--> B["🔭 Kalibrierung"]
	--> C["📐 Registrierung"]
	--> D["➕ Integration"]
	--> E["🌈 Farbmanagement"]
	--> F["✨ Optimierung"]
	--> G["💾 Archiv"]
	
	classDef start fill:#1565c0,color:white
	classDef process fill:#7e57c2,color:white
	classDef finish fill:#2e7d32,color:white
	
	class A start
	class B,C,D,E,F process
	class G finish
```

    4. Vergleich zweier Bearbeitungswege

    Sehr interessant für verschiedene Objekte:

    ```mermaid
flowchart TD

    A[Stacked Image]

    A --> B{Objekttyp}

    B -->|Nebel| C[Nebel Workflow]
    B -->|Galaxie| D[Galaxien Workflow]

    C --> C1[Gradient entfernen]
    C1 --> C2[Farbe verstärken]
    C2 --> C3[Details hervorheben]

    D --> D1[Hintergrund neutralisieren]
    D1 --> D2[Strukturen betonen]
    D2 --> D3[Sterne kontrollieren]


    style C fill:#283593,color:white
    style D fill:#6a1b9a,color:white
```

    6. Kleine Tricks für professionelle Optik

    Icons in Kästen

    Mermaid akzeptiert Unicode:

    "📷 Aufnahme"
"⚙️ Verarbeitung"
"🎨 Farbe"
"✨ Finale"

    Einheitliche Farben definieren

    classDef input fill:#1565c0,color:white
classDef process fill:#7b1fa2,color:white
classDef output fill:#2e7d32,color:white

    Dann:

    class Aufnahme input
class Stacken,Stretch process
class Export output

    Meine Empfehlung für deinen Aufbau

    Für deine Astrofotografie-Dokumentation würde ich drei Ebenen verwenden:

    Ebene 1 – Übersicht

    🌌 Objekt
 ↓
📷 Aufnahme
 ↓
⚙️ Preprocessing
 ↓
🎨 Processing
 ↓
✨ Final

    Ebene 2 – Workflow pro Objektklasse

    • Sonne

    • Mond

    • Planeten

    • Nebel

    • Galaxien

    • Kometen

    Ebene 3 – Detailseiten

    • einzelne Software

    • Parameter

    • Erfahrungen

    • Bildergebnisse
