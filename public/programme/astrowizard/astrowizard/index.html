    ⭐ Die 3‑Schritte‑Methode, die in AstroWizard wirklich Farben verschiebt

    Das ist die Methode, die funktioniert — egal wie dein Ausgangsbild aussieht.

    Sie basiert auf:

    1. Greens reduzieren

    2. Magenta erhöhen

    3. Warmth anwenden

    4. Blues senken

    5. Reds anheben

    Diese fünf Schritte zusammen erzeugen eine echte Farbverschiebung.

    ⭐ Die digitale Farbmisch‑Übersicht (für AstroWizard & RGB‑Kurven)

    🔥 1. Grundfarben und ihre Mischungen

    Digitale Farben entstehen nicht wie im Tuschkasten, sondern durch Anteile der drei Kanäle:

    • Rot (R)

    • Grün (G)

    • Blau (B)

    Alle Farben sind Kombinationen dieser drei.

    Orange = viel Rot + etwas Grün + wenig Blau

    → Wenn Blau fehlt, wird Orange zu Gelb → Wenn Grün fehlt, wird Orange zu Rot → Wenn Rot fehlt, gibt es kein Orange

    Gelb = Rot + Grün

    → Blau muss niedrig sein → Wenn Blau hoch ist, kippt Gelb zu Weiß

    Magenta = Rot + Blau

    → Grün muss niedrig sein → Wenn Grün hoch ist, kippt Magenta zu Pink

    Cyan = Grün + Blau

    → Rot muss niedrig sein → Wenn Rot hoch ist, kippt Cyan zu Weiß

    Pink = Rot + wenig Blau + kein Grün

    → Wenn Blau fehlt, wird Pink zu Rot → Wenn Grün leicht steigt, wird Pink zu Orange

    ⭐ 2. Was jede Kurve wirklich macht

    🔴 Reds

    • Rot ↑ → alles wird wärmer

    • Rot ↓ → Orange kippt zu Gelb

    🟢 Greens

    • Grün ↑ → Gelb entsteht

    • Grün ↓ → Magenta entsteht

    🔵 Blues

    • Blau ↑ → Bild wird kühler

    • Blau ↓ → Orange entsteht

    🟣 Magenta

    • Magenta ↑ → Grün verschwindet

    • Magenta ↓ → Pink wird wärmer

    🟡 Yellows (falls vorhanden)

    • Gelb ↑ → Orange wird stärker

    • Gelb ↓ → Rot wird dominanter

    🎚️ S‑Kurve

    • S ↑ → alle Farben werden intensiver

    • S ↓ → alles wird grauer → S verschiebt NICHT den Farbton

    ⭐ 3. Die Farbergebnis‑Matrix (dein neues Werkzeug)

    Hier ist die Übersicht, die du dir merken kannst:

    Ziel‑Farbe Erhöhe Senke
    Orange Rot ↑, Grün ↑ Blau ↓
    Gelb Rot ↑, Grün ↑ Blau ↓↓
    Rot Rot ↑ Grün ↓, Blau ↓
    Pink Rot ↑, Blau ↑ Grün ↓
    Magenta Blau ↑ Grün ↓
    Cyan Grün ↑, Blau ↑ Rot ↓
    Blau Blau ↑ Rot ↓, Grün ↓
    Grün Grün ↑ Rot ↓, Blau ↓

    👉 Diese Tabelle ist Gold wert. Damit kannst du jede Farbe gezielt erzeugen.

    ⭐ 4. Warum dein Bild „ausgereizt“ ist

    Du hast:

    • Blau fast vollständig entfernt

    • Grün stark reduziert

    • Rot + Magenta + Warmth stark erhöht

    • Sättigung global verstärkt

    Das bedeutet:

    👉 Orange kann nur entstehen, wenn noch etwas Grün + Blau vorhanden ist. Wenn beide fehlen, bleibt nur Rot + Magenta → Pink/Rot.

    Darum wirken manche Kurven nicht mehr.

    ⭐ 5. Die Kurzformel für Feuer‑Orange

    Wenn du irgendwann wieder Orange erzeugen willst:

    Orange = Rot ↑ + Grün ↑ + Blau ↓

    Oder als Kurven:

    • Reds +2–4 %

    • Greens +1–2 %

    • Blues −3–5 %

    Das ist die digitale Version von:

    Rot + Gelb = Orange Gelb = Rot + Grün

    ⭐ Fazit

    Ja — es gibt eine Übersicht. Und du hast sie jetzt vollständig.

    Mit dieser Farb‑Landkarte kannst du:

    • jede Farbe gezielt erzeugen

    • jede Farbe gezielt entfernen

    • verstehen, warum manche Kurven nichts tun

    • erkennen, wann ein Bild „ausgereizt“ ist

    • Farben bewusst steuern statt „probieren“
