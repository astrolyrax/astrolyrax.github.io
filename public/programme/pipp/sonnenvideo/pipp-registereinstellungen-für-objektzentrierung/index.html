    PIPP Einstellungen – Sonnenfinsternis (DWARF II)

    1. Image Files List

    • ✔️ Batch Mode
    • ❌ Join Mode

    Aufnahmeart

    • ✔️ Solar/Lunar Full Disc
    • ❌ Solar/Lunar Close-up
    • ❌ Planetary
    • ❌ ISS
    • ❌ AVI Archive
    • ❌ Planetary Animation (AVI)
    • ❌ Planetary Animation (GIF)

    2. Input Options

    (keine speziellen Änderungen notwendig – Standardwerte)

    3. Processing Options

    Frame Stabilisation

    • ✔️ Frame Stabilisation Mode: Object/Planetary

    Object Detection

    • ✔️ Enable Object Detection
    • Minimum Object Size: 5
    • ✔️ Auto Object Detection Threshold
    • Object Detection Threshold: 20

    Centering

    • Centre Object In Each Frame: None

    Cropping / Resize

    • ❌ Enable Cropping
    • ❌ Resize Frames

    Quality / Exposure

    • ❌ Reject Frames With Overexposed Pixels

    4. Quality Options

    Quality Estimation

    • ❌ Enable Quality Estimation
    • ❌ Reorder Frames In Quality Order

    Quality Limiting

    • ❌ Only Keep The Best Quality Frames
    • Number Of Frames To Keep: (irrelevant)

    Quality Algorithm

    • ✔️ Default PIPP Quality Algorithm

    Subsample Values

    • Minimum Subsample Value: 3
    • Maximum Subsample Value: 5
    • Subsample Increment Value: 1

    Weighting

    • ❌ Enable Quality Weighting

    5. Animation Options

    Forward Play

    • ❌ Play All Frames In Forward Order
    • Pause Final Frame: 1

    Reverse Play

    • ❌ Play All Frames In Reverse Order After Forward Play
    • Pause Final Frame: 1

    Sequence Repeat

    • ❌ Repeat All Frames In Sequence
    • Sequence Repeats: 1
    • ❌ Do Not Do Reverse Play In Final Repeat

    6. Output Options

    Format

    • ✔️ Output Format: SER

    Output Directory

    • ✔️ Default (Source File Directory)

    Output Subdirectory

    • ✔️ Enable
    • Subdirectory Name: pipp_
    • ✔️ Append date and time

    Filename

    • Prefix: (leer)
    • Suffix: _pipp

    RGB Splitting

    • ❌ Colour (RGB) Channel Splitting

    Frame Dropping

    • Frames To Drop After Each Frame: 0

    TIFF Naming (irrelevant für SER)

    • ✔️ Keep Original Image Filenames
    • ✔️ Add Leading Zeros
    • ❌ Disable Image Frame Renumbering
    • ❌ Include Quality Value In Filename

    7. Do Processing

    • (nur Start – keine Einstellungen)
