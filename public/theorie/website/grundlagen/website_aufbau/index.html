    Aufbau einer WebSite

    Astrofotografie-Webseite mit GitHub Pages erstellen

    Ziel

    Wir erstellen kostenlos eine Webseite mit folgender Struktur:

    Startseite
│
├── Über mich
├── Meine Ausrüstung
├── Deep Sky
├── Planeten
├── Beobachtungsberichte
└── Kontakt

    Die Webseite wird anschließend unter einer Adresse wie

    https://dein-benutzername.github.io

    erreichbar sein.

    Schritt 1: GitHub-Konto erstellen

    1. Öffne:

      https://github.com

    2. Klicke auf Sign up

    3. Benutzerkonto anlegen

    Beispiel:

    Benutzername: astrolyrax
    1. E-Mail bestätigen

    Schritt 2: Neues Repository anlegen

    Nach der Anmeldung:

    1. Auf New Repository klicken
    2. Als Namen eingeben:

    Plain Text

    andreas-ulbricht.github.io

    Wichtig:

    Der Repositoryname muss exakt lauten:

    Plain Text

    .github.io

    Beispiel:

    Plain Text

    astrolyrax.github.io

    Folgende Optionen aktivieren:

    Plain Text

    ✅ Public

    ✅ Add README

    Danach:

    Plain Text

    Create Repository

    Schritt 3: Erste Webseite erzeugen

    Im Repository:

    Add file

    ↓

    Create new file

    Dateiname:

    Plain Text

    index.html

    Inhalt:

    HTML

    Hier präsentiere ich meine Aufnahmen von Deep-Sky-Objekten,

    Planeten und besondere Beobachtungsnächte.

    Weniger anzeigen

    Schritt 4: Weitere Seiten anlegen

    Für jede Rubrik eine Datei erstellen.

    about.html

    HTML

    Mein Name ist Andreas und ich beschäftige mich leidenschaftlich

    mit Astrofotografie.

    index.htmlZurück

    Weitere Zeilen anzeigen

    equipment.html

    HTML

    index.htmlZurück

    Weitere Zeilen anzeigen

    Schritt 5: GitHub Pages aktivieren

    Im Repository:

    Settings
↓
Pages

    Unter:

    Plain Text

    Build and deployment

    einstellen:

    Plain Text

    Source: Deploy from a branch

    Branch:

    Plain Text

    main

    Ordner:

    Plain Text

    / (root)

    Speichern.

    Nach wenigen Minuten erscheint:

    Plain Text

    Your site is live at

    https://dein-benutzername.github.io

    Schritt 6: Bilder hochladen

    Im Repository einen Ordner anlegen:

    Plain Text

    images

    Beispiel:

    Plain Text

    images/

    ├── m42.jpg

    ├── m31.jpg

    └── jupiter.jpg

    Bild einbinden:

    HTML

    images/m42.jpg

    Schritt 7: Deep-Sky-Galerie erstellen

    Datei:

    Plain Text

    deepsky.html

    Beispiel:

    HTML

    images/m42.jpg

    Belichtungszeit: 60 x 120s

    Kamera: ASI294MC Pro

    Für jedes Objekt denselben Aufbau verwenden.

    Schritt 8: Professioneller werden

    Später kannst du hinzufügen:

    Eigenes Design

    Mit Bootstrap:

    HTML

    https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css

    Eigene Domain

    Beispiel:

    Plain Text

    astro-ulbricht.de

    Kosten:

    Plain Text

    ca. 10 € pro Jahr

    GitHub Pages unterstützt eigene Domains direkt.

    Empfohlene spätere Struktur

    Plain Text

    andreas-ulbricht.github.io

    │

    ├── index.html

    ├── about.html

    ├── equipment.html

    ├── deepsky.html

    ├── planets.html

    ├── reports.html

    ├── contact.html

    │

    ├── images

    │ ├── m42.jpg

    │ ├── m31.jpg

    │ ├── jupiter.jpg

    │ └── saturn.jpg

    │

    └── css

    └── style.css

    Mein Tipp für dein Astrofotografie-Projekt

    Statt sofort viele HTML-Dateien von Hand zu pflegen, würde ich beim zweiten Schritt auf einen sogenannten GitHub Pages Jekyll-Theme oder ein Astro-/Hugo-Template für Fotografen wechseln. Dann genügt oft das Hochladen neuer Bilder und kurzer Markdown-Dateien, und die komplette Galerie wird automatisch aufgebaut.

    Für den allerersten Start ist die oben beschriebene Variante jedoch ideal: Du hast nach 30 Minuten deine erste öffentliche Astrofotografie-Webseite online und lernst gleichzeitig die Grundlagen von GitHub Pages kennen.

    Ja, gerne. Für den Einstieg würde ich dir sogar empfehlen, die komplette Anleitung als README.md in deinem Projekt abzulegen. Dann hast du später immer eine Schritt-für-Schritt-Dokumentation zur Hand.
